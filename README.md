# Aegis & Fur Landing

Public marketing/explainer page for **Aegis & Fur** — *"Every tail deserves a guardian."*
A tiered glucose-monitoring platform for diabetic dogs, built by integrating proven
medical hardware instead of inventing a new biosensor. (Rebranded from plain "Aegis"
to avoid conflict with an existing business.)

## What's here

A single static page (`index.html`), no build step — same pattern as
`physicalkey-landing`. Real content pulled from the actual verified state of
[canine-cgm-bridge](https://github.com/humbertowgw-maker/canine-cgm-bridge)
as of 2026-08-20: 4 product tiers, 54 passing backend tests, 2 real ESP32
firmware builds, 1 real iOS companion app.

## Local development

Open `index.html` directly, or serve the directory with any static file
server — nothing to build or install.

## Deployment

Deployed to Vercel. Push to `main` to update.
